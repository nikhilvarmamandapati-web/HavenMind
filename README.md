Haven Mind - 100% Pure Flutter Community App
Haven Mind is a cross-platform mental wellness community application built with Flutter 3 and Riverpod.
Key Features Included:
Silent Co-Presence Breathing Sanctuary (lib/screens/breathe_screen.dart): Synchronous 4-4-4-4 Box Breathing with hardware-accelerated animations and haptics.
Ephemeral Vent Vault (lib/screens/vent_vault_screen.dart): Safe private thought container with "Burn & Disappear" animation and cognitive reframing advice.
Intent-Based Community Feed (lib/screens/community_screen.dart): Stories categorized by user needs with 1-tap "Gentle Mode" trigger shielding.
Kindness Cards (lib/screens/kindness_screen.dart): Exchange micro-encouragements and request support beacons.
5-4-3-2-1 Sensory Grounding (lib/screens/grounding_modal.dart): Immediate panic relief tool with 24/7 crisis hotlines.
